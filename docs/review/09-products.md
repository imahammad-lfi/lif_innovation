# Products & Accelerators — strategic website review

**Review date:** 8 November 2026. **Group:** `products`. **Verdict:** retain the hub and all eight product URLs; rework all nine pages. No redirect, product retirement or change to the five-portfolio taxonomy is recommended.

Retain the hub and all eight product URLs, but rework them as enterprise evaluation pages rather than category teasers. The hub is deck-aligned; most detail pages repeat their own names and claims instead of showing product operation, evidence or procurement fit. Prioritise AI Governance ownership disclosure, real software demonstrations, product-aware conversion and verified security/deployment/licensing information. No page retirement or taxonomy change is recommended.

**Review basis:** complete reviewer brief and corporate-deck transcription; all nine page JSON files; rendered production HTML through HTTP GET. Screenshot coverage and visual observations are recorded below. No site files, builds, seed data or services were changed. External destinations were assessed as local outbound journeys, not audited externally.

**Priority key:** P1 = must fix; P2 = should fix; P3 = refinement. Section numbers refer to the original JSON array, not the proposed future numbering. Added sections use the insertion boundary before the existing section with that number; multiple additions at the same boundary should appear in listed order. Empty CMS headings are identified by their actual rendered default wording. Keep pages compact: added evidence replaces repetition, not a reason to append generic corporate content.
