# Request 2026-11-10 (h) — product pages: logo in place of the text title in the hero

User: on a product page (e.g. textIQ) the hero shows "textIQ" as text with the tagline; show the product logo in
place of the text, for every product. Approved: logo only (no text name next to it).

## Root cause
- All 13 product pages use `sections.page-hero` (title, subtitle, background image, anchor tabs); it had no logo
  field in Strapi or in `page-hero.tsx`, so it could only render the name as text.
- Logos already exist in `seed/assets/custom/logos/<slug>.png` (8 products) and were wired to the mega menu, the
  Products hub and home tiles only (`apply.py` `with_logo`, `deck.py`).
- No logo file yet: delivery-accelerators, digital-twin-suite, intelligent-workflow-automation, power-bi-ai-ml,
  predictive-analytics-suite. These keep the text title until logos are supplied.

## Changes
- apps/cms/src/components/sections/page-hero.json: optional `logo` (single image). Other pages are unaffected.
  types/generated/components.d.ts updated to match.
- apps/web/src/components/sections/common/page-hero.tsx: with a logo, the h1 holds an sr-only title, so SEO and
  screen readers keep the name, plus the logo on a white rounded plate (the logos use dark/blue lettering), sized
  40/48/56/64 px high by breakpoint, with a max width so wide wordmarks scale down. Without a logo it is unchanged.
- seed/custom/apply.py: `patch_product_hero` sets the hero logo for every `/products-and-accelerators/<slug>` page
  that has `custom/logos/<slug>.png`, or removes it when there's no file. A new product gets its logo by adding
  the file.
- seed/data regenerated (apply.py). 8 industry images in seed/assets/custom/industries were mode 600 and unreadable by
  the seed container (EACCES), so they were made world-readable with chmod (no content change).

## Rollout and checks
- seed:validate: 84 documents valid. eslint (page-hero.tsx, header) and tsc: clean.
- CMS parity before import: every page's updatedAt was the 10:52 seed run, so no editor edits were overwritten.
- `docker compose up -d --build cms` (new field), then seed `--only=pages`: 71 updated, media 101 reused. Webhook
  emit "aborted" errors at exit are the known seed-process issue (see 10e); the web rebuild covers it.
- Web `pnpm build`, static/public copied to standalone, pm2 `lf-web` restarted.
- Served HTML: the hero h1 has the sr-only title plus the logo on textiq, vajrax, ai-governance, edupilot, finsight,
  linkworks, testoriumz and vectorx; the 5 pages without a logo keep the text h1.
- Visual check in a browser not run here (no Playwright). AI Governance is a very wide wordmark (9:1), so check
  that it is legible on phones.
