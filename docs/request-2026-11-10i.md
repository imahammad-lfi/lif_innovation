# Request 2026-11-10 (i): faster home hero, contact-page map stays beside the cards

## Asked
1. The home hero text and slides should change every 4 seconds (was 6).
2. Contact us › Our offices: the map is beside the first four office cards, but by the Australia and USA cards it
   has scrolled up out of view.

## Changes
- seed/custom/deck.py: `autoplaySeconds` = 4 for the home hero. seed/data regenerated (apply.py).
- apps/web/src/components/sections/home/hero-slider.tsx: fallback when the field is empty is now 4.
- apps/cms/src/components/home/hero-slider.json: `autoplaySeconds` default is 4 (the min is still 4, the max 15).
- apps/web/src/components/primitives/deck.tsx: `DeckStage` uses `overflow-clip` instead of `overflow-hidden`.
  `overflow: hidden` makes the section a scroll container, so the map's `lg:sticky` never stuck. `clip` cuts off
  the overflow the same way but lets sticky children work. This applies to every DeckStage section; nothing else in
  them depended on it being a scroll container.

  The "Could not emit entry.publish" pool-timeout errors at the end are the known seed-process issue (see 10e).

- Served HTML: home hero `interval: 4000`. On /contact-us, `#our-offices` has `overflow-clip` and the CSS contains
