# Request 11 Nov 2026 (10:01): product logos on banners, AI Governance menu logo

## Request

> "Add products and accelerator transparent background logos on the banner image - see attached. See for example second
> image testoriumz." (Attachments: the Linkworks banner with a text title, and a testoriumz mock-up with the logo in place
> of the title.) Earlier in the same thread (07:58): the AI Governance entry under Cyber Security in the Products &
> Accelerators menu showed text, not a logo pill like VajraX and VectorX.

## Findings

- **Menu.** `seed/custom/apply.py` `with_logo()` deliberately skipped logos wider than 7:1. The AI Governance PNG is
  837×92 (9.1:1), so it was the only product shown as text in the menu. At the menu plate size (118×34, logo area
  98×22) the wordmark draws about 11 px tall, which is legible.
- **Banners.** All product logos are made for light backgrounds: black or navy wordmarks (Linkworks, testoriumz, VajraX,
  VectorX, AI Governance) disappear on the dark banners, and the brand blue used by textIQ, FinSight, EduPilot and the
  "AI" of AI Governance (#1848c0 to #1860f0) reaches only about 2.5:1 contrast on the banner. A dark-background version
  of each logo was therefore needed. The light-background originals stay on the white menu plates and product cards.
- Only the eight products have logos. The five accelerator families have no logo, so their banners keep the text title.

## Changes

1. **On-dark logo versions** (`seed/assets/custom/logos/on-dark/<slug>-on-dark.png`, 8 files, transparent PNG, trimmed
   to the artwork). Generated from the existing logos only, no new artwork: black, navy and their grey anti-aliasing
   become white (alpha kept); brand blue is lifted to a lighter tint of the same hue (HLS lightness at least 64%);
   orange and yellow are unchanged. Prototyped against each product's real banner image (original, white wordmark only,
   white wordmark plus lifted blue); the third version was chosen because it reads on every banner and matches the
   lighter blue petal in the testoriumz mock-up.
2. **CMS.** `sections.page-hero` has a new optional `logo` image field (`apps/cms/src/components/sections/page-hero.json`).
   Editors can set or remove it per page (Content Manager → Page → Page hero → logo).
3. **Website** (`apps/web/src/components/sections/common/page-hero.tsx`). When a logo is set, it replaces the visible
   title. The h1 keeps the product name as screen-reader-only text and the image is decorative (empty alt), so the
   name is announced once and the heading text stays for search engines. Logos are sized by area so compact marks
   and long wordmarks look equally weighted: width = √(area × aspect), area 6,800 / 10,000 / 14,000 / 17,500 px²
   (phone / 640px+ / 1280px+ / 1920px+), capped at min(84vw, 560px), with a soft drop shadow.
4. **Seed pipeline.** `deck.product_hero_logo()` sets the banner logo on the eight product pages; `with_logo()` no
   longer excludes wide wordmarks. Regenerated seed: exactly 10 changes (8 banner logos, plus the AI Governance logo
   in the Products & Accelerators menu and in the Services menu's Cyber Security "Linkfields IP" group, which uses the
   same rule; the Services menu shows those IP links as text chips, so it looks the same as before).
5. **QA tool.** `tools/design_conformance_qa.py` skips `.sr-only` text (it is never drawn, so it has no type size).
6. **Docs.** DESIGN-SYSTEM.md (logo plates rule updated, product banner logo rules added), PRODUCTS-AND-ACCELERATORS.md
   (menu logos, banner logos and the editor steps), SECTION-CONTRACT.md (page-hero fields).
