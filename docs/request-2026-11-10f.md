# Request — 10 Nov 2026 (22:45): large screens, TVs and projectors

> "When displayed on a big monitor, screen, TV or projector it's showing a gap between text and globe, and the other
> two screenshots are the same (footer, contact form). Please make all screens fit — monitors, projectors, TVs etc."

## Root cause
- The header kept its content in a centred 1920px frame (`mx-auto max-w-[1920px] px-gutter`), but most sections used
  only `px-gutter` (a fixed 100px gutter above 1561px). On screens wider than 1920px the header stayed centred while
  section content (hero copy, contact form, footer, overview, banners…) ran out to 100px from the screen edges.
- The hero globe was positioned `right-[5vw]` from the screen edge, so on a 4K screen the copy sat at the far left and
  the globe at the far right (2,215px gap at 3840px; 3,431px at 5120px).
- The hero partner marquee repeats its logo row three times; on screens ≥3440px two copies no longer covered the
  strip, leaving a visible gap.
- The desktop hero had a fixed height (860px; 1,000px from 1561px). On 1366×768 laptops, 720p/768p projectors and
  1080p screens with browser chrome, the logo strips were below the fold.

## Changes (web, deployed 23:10)
- `globals.css`: `px-gutter` / `pl-gutter` above 1561px = `max(100px, calc((100% - 1920px) / 2 + 100px))` → every
  section keeps content in the header's 1920px frame (1720px content) on any width; backgrounds stay full-bleed.
  New `px-gutter-box` (fixed gutter) for boxed elements; new `short:` variant (≥769px wide and ≤760px tall).
- Header bar, mega-menu panel and section-tab bar: removed the now-redundant `mx-auto max-w-[1920px]`.
- Career slider heading (boxed 900px): `px-gutter-box`.
- Hero: globe offset `right-[max(5vw,calc(50%-864px))]`; desktop hero height follows the screen
  (`clamp(640/650px, 100svh, 800/860px)`, wide `clamp(680/720px, 100svh, 920/1000px)`; phones unchanged); globe size
  capped by the available height; strips keep the full-bleed bar but their content sits in the 1920px frame (marquees
  fade at the frame edges and always fill); `short:` screens get slightly tighter hero spacing (38px title, 15.5px
  description, 28px chips) — no content hidden.
- Footer: decorative world map positioned relative to the frame.
- `docs/DESIGN-SYSTEM.md`: layout rules for the frame, `px-gutter-box`, `short:` and the new check tool.
- New tool `tools/large_screen_qa.py` (17 pages × 14 sizes, 1024×768 → 5120×1440).

## Note
- The dev server served the old gutter CSS from a stale Turbopack cache after the `globals.css` edit (component class
  changes did come through). Restarting with `.next/dev` cleared fixed it; production build CSS verified to contain
  `padding-inline:max(100px,50% - 860px)`.
