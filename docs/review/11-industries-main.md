# Industries hub and eight main industry pages

Group: `industries-main` · Review date: 8 November 2026 · Production review: `http://127.0.0.1:3001`

## Summary

Retain all eight industry URLs and the client-required hub grid, but rebuild the buyer story around industry workflows, integrated portfolios, selected Linkfields IP and evidence. Fix Manufacturing’s false business description and Telecom’s opaque legacy copy first. The newer pages have useful scope but duplicate it across capability cards and a hidden carousel; replace that repetition with a compact delivery map, visible use-case tiles, proof and contextual conversion.

**Decision:** Rework, do not retire, all nine pages. P1 fixes are identity/positioning/proof problems; P2 fixes improve depth, consistency and conversion. P3 identifies useful material to retain.

**Method:** Read the complete review brief, corporate-deck transcription, design rules, all nine page JSON files and global fallbacks. Checked rendered H1/title/description/canonical and relevant portfolio/product/sector destinations using HTTP GET only. Desktop full-page slices and mobile checks are documented below. No site files or services were changed.

**Position convention:** Existing section numbers are the original 1-based JSON-array positions. “Add before #n” means insert before that original section; multiple additions at that position appear in the order listed. A moved section’s destination is stated in its recommendation. Blank CMS headings are shown with the exact global fallback visible on the site.
