## Changes
- `apps/cms/providers/email-graph/index.js` (new): Strapi email provider for Microsoft Graph `POST /users/{sender}/sendMail`
  with the client-credentials flow (token cached until shortly before expiry). Maps to/cc/bcc/replyTo
  ("Name <addr>" strings or arrays), HTML/text body, inline `cid` attachments (the logo) and headers (sent as MIME
  after the review fixes below). Errors include the Graph error code, so they end up in the lead's `emailError`.
- `apps/cms/config/plugins.ts`: `EMAIL_PROVIDER=graph` selects the provider by module path (Strapi loads non-@strapi
  providers via `require(name)`); anything else keeps Nodemailer/SMTP as before.
- `docker-compose.yml`: passes `EMAIL_PROVIDER` and `MS_GRAPH_*` to the cms service.
- `.env.example`, `apps/cms/.env.example`: new variables (empty). `docs/CMS-BRANDING-AND-EMAIL.md` §5: Graph set-up.
- Secrets are only in the root `.env` (gitignored).

## Code-review fixes (same day)
- Provider is now the local package `strapi-provider-email-graph` (`file:providers/email-graph` in package.json,
  lockfile updated, Dockerfile copies `providers/` before `npm ci`), loaded by name: no cwd/absolute path, which
  Strapi lower-cases and so broke on case-sensitive paths.
- Missing `MS_GRAPH_*` no longer throws in `init` (that stopped the whole CMS at boot); it logs, and the send fails
  so the lead records `emailStatus: failed`.
- Without an explicit `from`, the From address is the sender mailbox (`MS_GRAPH_SENDER`) with the `EMAIL_FROM`
  display name, so setting `MS_GRAPH_SENDER` alone never needs Send As.
- Messages are sent as base64 MIME built by Nodemailer's composer: keeps the text/plain alternative, inline logo and
  `Auto-Submitted`; adds `X-Auto-Response-Suppress: All`. `MS_GRAPH_SAVE_TO_SENT_ITEMS` dropped (not available for
  MIME sends; copies go to Sent Items).
- 429/503/504 retried up to 4 attempts honouring Retry-After; 401 clears the cached token and resends once;
  concurrent sends share one in-flight token request.
- Terraform: `enquiry_email_provider` (`none` default | `graph`), `ms_graph_tenant_id`, `ms_graph_client_id`,
  `ms_graph_sender`, `enquiry_notify_to`; operator-populated secret `…/ms-graph-client-secret` (output
  `ms_graph_client_secret_arn`); CMS task env/secrets and execution-role policy. Single server: `apps/cms/.env`.
- `.playwright-mcp/` gitignored and deleted.
- Not changed: review item on `seed/assets/s3/*.png` replaced in place. `seed.mjs` keeps a sha1 per seeded file and
  re-uploads changed bytes, so the new images do reach a CMS seeded by this pipeline; those files are uncommitted user
  edits.
- Checks: `terraform fmt -check` and `terraform validate` OK; CMS image rebuilt and healthy with the provider resolved
  by name; mocked-fetch tests (MIME parts and headers, From/sender, missing secret, 429/503 retry, 401 refresh, 400
  no retry, give-up after 4, single token request for 5 concurrent sends) all pass; real MIME send to the requester's
  mailbox: Graph 202.
